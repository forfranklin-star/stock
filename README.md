# A股智能量化分析系统

一个基于 Python + Flask + ECharts 的在线网页版股票分析程序，支持最优买卖点计算、技术指标相关性分析、可解释数学模型构建、历史回测和实时信号生成。

## 功能概览

| 模块 | 说明 |
|------|------|
| **最优买卖点** | 贪心峰谷法搜索时间段内最大收益交易序列，输出每笔买卖日期/价格/收益率 |
| **技术指标** | MACD、RSI(6/14)、KDJ、布林带、MA5/10/20/60、成交量变化率、OBV、WR、CCI 等 23 个指标 |
| **相关性分析** | 点二列相关系数 + t检验显著性，找出与买卖点最相关的指标组合及阈值 |
| **数学模型** | 阈值加权打分系统（Sigmoid映射），明确输入指标、权重、规则，可视化模型结构 |
| **历史回测** | 初始100万全仓，手续费万2.5+印花税千1，输出资金曲线/最大回撤/年化/胜率/盈亏比 |
| **预测准确率** | 预测买入后5日上涨概率、卖出后5日下跌概率 |
| **实时信号** | 最新交易日数据计算指标，输出买入/卖出/持有信号及概率、关键指标状态 |

## 快速开始

### 1. 环境要求

- Python 3.9+
- 网络连接（用于获取股票数据）

### 2. 安装依赖

```bash
cd stock_analyzer
pip install -r requirements.txt
```

依赖清单：
- `flask` - Web 框架
- `akshare` - A股数据接口（免费，无需Token）
- `pandas` / `numpy` - 数据处理
- `scipy` - 统计检验
- `scikit-learn` - 机器学习工具

### 3. 启动程序

```bash
python app.py
```

启动成功后会显示：
```
============================================================
  A股股票分析系统启动中...
  访问地址: http://127.0.0.1:5000
============================================================
```

### 4. 打开网页

在浏览器中访问 **http://127.0.0.1:5000**

也可以直接双击打开 `index.html` 文件（需确保后端已启动，页面会自动连接 `http://127.0.0.1:5000`）。

## 使用方法

### 分析历史数据

1. 在**股票代码**输入框中输入6位A股代码（如 `600519` 贵州茅台、`000001` 平安银行、`600118` 中国卫星、`600141` 兴发集团）
2. 选择**起始日期**和**结束日期**（建议至少1年以上，以确保MA60等指标有效）
3. 点击**开始分析**按钮
4. 等待分析完成（通常5-15秒，取决于数据量）
5. 在下方标签页中查看各模块结果：
   - **K线与买卖点**：K线图上标注最优买卖点（红▲买/绿▼卖），下方为模型买卖概率曲线
   - **最优交易明细**：每笔交易的日期、价格、持有天数、收益率
   - **指标相关性**：买点/卖点相关性排序条形图，买点前后指标均值变化
   - **数学模型**：模型结构可视化、公式、买点/卖点规则列表
   - **回测结果**：回测指标卡片、资金曲线图、交易明细表
   - **预测准确率**：买卖预测准确率及信号样本

### 获取实时信号

1. 输入股票代码
2. 点击**获取实时信号**按钮
3. 系统自动获取最新交易日数据，计算模型信号
4. 在**实时信号**标签页查看：操作建议（买入/卖出/持有）、信号强度、买卖概率、触发指标状态

## 核心算法说明

### 最优买卖点（贪心峰谷法）

对于"允许多次交易、不可同时持有多个仓位"的场景，贪心算法在每个局部谷底买入、下一个局部峰顶卖出，理论上可获取最大收益。设置最小收益率阈值（默认1%）过滤噪声交易。

### 相关性分析

使用**点二列相关系数**（Point-Biserial Correlation）衡量连续型技术指标与二元买卖点标签的相关性，等价于 Pearson 相关系数。同时计算 p 值进行显著性检验（p < 0.05 为显著）。

### 数学模型（阈值加权打分系统）

1. 选取与买点/卖点相关性最高的 Top 6 指标
2. 阈值 = 事件点均值与非事件点均值的中点
3. 每个指标的信号强度 = Sigmoid(标准化偏离度 × 方向符号)
4. 综合概率 = Σ(权重 × 信号强度) / Σ权重
5. 买入阈值概率 ≥ 0.60 触发买入，卖出阈值概率 ≥ 0.60 触发卖出

### 回测规则

- 信号在T日收盘后生成，T+1日开盘价执行（更贴近真实交易）
- 全仓买卖，买入股数取整到100股
- 买入手续费：成交金额 × 0.025%（最低5元）
- 卖出手续费：成交金额 × 0.025% + 印花税 0.1%
- 期末未平仓按最后收盘价强制平仓

## 数据缓存

- 历史日线数据缓存至 `cache/` 目录，有效期24小时
- 实时数据缓存有效期2小时
- 缓存以 pickle 格式存储，按函数参数+股票代码+日期范围生成唯一键
- 如需强制刷新数据，删除 `cache/` 目录即可

## 常见问题

**Q: 提示"未获取到股票数据"怎么办？**
A: 检查股票代码是否正确（6位数字），确认日期范围合理（起始日期早于结束日期），网络是否正常。部分新股可能历史数据不足。

**Q: 分析速度慢？**
A: 首次获取数据需要从网络下载，后续使用缓存会快很多。建议日期范围不要超过5年。

**Q: 回测收益为负或交易次数为0？**
A: 模型基于选定时间段内的最优买卖点训练，如果该时间段内趋势不明显或指标与价格相关性低，模型信号可能较少。尝试扩大日期范围或更换股票。

**Q: 实时信号显示"持有"？**
A: 模型仅在买点概率或卖点概率超过0.60阈值时给出明确买卖信号，否则建议持有。这是正常的保守策略。

**Q: akshare接口报错？**
A: akshare依赖东方财富等第三方数据源，偶尔会因接口变更或网络问题失败。尝试升级 `pip install -U akshare`，或稍后重试。
